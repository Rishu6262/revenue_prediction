# ☕ Coffee Shop Revenue Prediction App

An AI-powered Machine Learning web application that predicts the **daily revenue of a coffee shop** based on operational and business parameters.

This project uses a trained **Random Forest Regression model** and provides an interactive **Streamlit dashboard** where users can adjust business metrics and instantly receive revenue predictions.

## 📌 Project Overview

Coffee shop owners often need quick revenue estimates based on changing business conditions.

This application helps predict estimated daily revenue using machine learning by considering:

- Number of customers per day
- Average order value
- Operating hours
- Number of employees
- Daily marketing spend
- Location foot traffic

The model analyzes these inputs and predicts expected revenue instantly.
